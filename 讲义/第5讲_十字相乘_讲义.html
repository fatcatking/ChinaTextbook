一、这一讲解决什么问题

第 1–4 讲处理「看得出结构」的式子：有公因式就提、像公式就代、项多就分组、不成形就拆项添项。但遇到 x² + 5x + 6——三项、无公因式、不是完全平方、分组也分不动，前面四招全部失效。

十字相乘是专门对付二次三项式的第五招，也是第 6 讲（长十字）、第 7 讲（换元）、一元二次方程与二次函数的共同前置。只背口诀不究原理，到第 6 讲必然卡住。更高次的式子，要先换元变成二次三项式，再来十字。

前置检查（10 分钟）

  1. 分解 6x³ − 9x² + 3x
  2. 分解 x⁴ − 16
  3. 展开 (x+2)(x+3)

第 3 题做不出，先回去补乘法分配律，不要往下走。

★ 第 1 题现阶段能提到 3x(2x² − 3x + 1) 就算过关。括号里再用第 4 讲的拆项，或学完 5.3 后继续分，整式是 3x(2x−1)(x−1)。不要把已经提出的 3x 丢掉。第 2 题用两次平方差：x⁴ − 16 = (x²+4)(x²−4) = (x²+4)(x+2)(x−2)。x²+4 是平方和，在有理数范围内不能再分，不要写成 (x+2)(x−2)。

二、第一性原理：十字相乘只是乘法竖式倒着写

(x + 2)(x + 3) = x·x + 3x + 2x + 2·3 = x² + (2+3)x + 2×3 = x² + 5x + 6

一般地：(x + a)(x + b) = x² + (a+b)x + ab

更一般：(px + q)(rx + s) = pr·x² + (ps + qr)x + qs

所以分解 ax² + bx + c，就是找两列数，使第一列之积 = a、第二列之积 = c、交叉相乘之和 = b：

左列右列横着读
第 1 行pq因式 (px + q)
第 2 行rs因式 (rx + s)

竖着乘：p·r = a（首项系数），q·s = c（常数项）。

交叉乘再相加：p·s + q·r = b（必须等于一次项系数）。两行各读出一个一次因式。它成立的唯一理由是乘法分配律，没有别的。

判断优先级（按这个顺序走）

a、b、c 是排成 ax² + bx + c 之后的三个系数，不是纸上从左到右看到的三个数。所以先排降幂，再谈系数和。

步骤检查动作
① 有公因式？ 字母，或绝对值大于 1 的公约数，一次提净。式子还没排好序时，先不要提 −1。
② 按降幂排了吗？首项为负？ 先排成 ax² + bx + c；二次齐次式排成 ax² + bxy + cy²。若 a < 0，再提 −1，使 a > 0。后面的 a、b、c 都指排好之后的系数。
③ a + b + c = 0？ 直接写 (x−1)(ax − c)，见 5.5。c 带着自己的符号。二次齐次式写 (x−y)(ax − cy)，第二因式是 ax − cy，不是 ax − c。
③′ a − b + c = 0？ 直接写 (x+1)(ax + c)。二次齐次式写 (x+y)(ax + cy)。
④ a = 1？ 找两数：积 = c、和 = b。
⑤ a ≠ 1？ 拆 a = p·r（p、r 都取正）、c = q·s，验 p·s + q·r = b。不对就换因数对，包括上下对调。
⑥ 还是分不出？ 先确认它是二次三项式。提净并且 a > 0 之后，Δ = b² − 4ac 不是完全平方数（0, 1, 4, 9, 16, …），才说明在有理数范围内不能分成两个一次因式。Δ = 0 也算完全平方，可以分成两个相同的一次因式。只试了几组没凑上，不能据此放弃。式子根本不是二次三项式，回到第 3、4 讲。系数里有分数时，先通分乘成整系数再算 Δ。
⑦ 最后 乘回去验算，并检查每个因式是否还能再分。

第 ⑥ 步回答「什么时候该放弃」：十字相乘只解决能在有理数范围内分成两个一次因式的二次式。对这样的二次三项式，判别式不是完全平方数时，分组和拆项也变不出有理系数的一次因式。

三、五个小节（对应原书 5.1–5.5）

5.1 知己知彼 · 首项系数为 1

书上的角度很妙：学生也可以编题。取 (x+2)(x+3) 展开得 x²+5x+6，反过来就是一道题。6 的因数拆法不计次序共四种，正好对应四道例题：

6 的拆法和多项式分解结果原书
2×35x² + 5x + 6(x+2)(x+3)例 1
(−1)×(−6)−7x² − 7x + 6(x−1)(x−6)例 2
(−2)×(−3)−5x² − 5x + 6(x−2)(x−3)例 3
1×67x² + 7x + 6(x+1)(x+6)例 4

一句话：先列常数项的所有因数对，再挑「和 = 一次项系数」的那组。别一上来就猜。

5.2 熟能生巧 · 符号判断

书上原话：常数项为正时两因数同号；常数项为负时两因数异号。（本小节默认首项系数为 1，而且已经提成正的。）

cb两因数符号例题
c > 0b > 0同为正例 5　x² + 6x + 8 = (x+2)(x+4)
c > 0b < 0同为负例 6　x² − 6x + 8 = (x−2)(x−4)
c < 0b > 0异号，绝对值大的为正例 7　x² + 7x − 8 = (x+8)(x−1)
c < 0b < 0异号，绝对值大的为负例 8　x² − x − 6 = (x+2)(x−3)

例 8 的两数是 2 和 −3：积 = −6，和 = −1，|−3| > |2|，所以绝对值大的那个为负。若两个因数的绝对值相等，和只能是 0，式子其实是平方差（如 x² − 4），用第 2 讲的公式，不必硬套「谁的绝对值大」。

例 9　x + 12 − x²（原书原式未按降幂排）

先排降幂：x + 12 − x² = −x² + x + 12。首项系数是 −1，再提 −1：

−x² + x + 12 = −(x² − x − 12)。

括号里 a = 1，c = −12，b = −1。两数 3 与 −4：积 = −12，和 = −1。所以 x² − x − 12 = (x+3)(x−4)。

路径 A（先提 −1，建议初学走这条）：x + 12 − x² = −(x+3)(x−4)。

路径 B（不提 −1，直接十字）：

−1413 竖乘 (−1)×1 = −1，4×3 = 12；交叉 (−1)×3 + 4×1 = 1。读出 (x+3)(−x+4)。

两条路径相等，是因为 −(x−4) = −x + 4，所以 −(x+3)(x−4) = (x+3)(−x+4)。−x+4 和 4−x 只是同一个因式的两种写法，不能拿这句代替上面的符号搬家。

5.3 再进一步 · 首项系数 ≠ 1

同时拆两列。试错原则：交叉和不对，就换 a 的分解、换 c 的分解，或上下对调。步骤 ② 已经把 a 提成正数，a 的两个因数都取正，负号只放在常数那一列，要试的组合少一半。

例 10　6x² − 7x + 2 = (2x−1)(3x−2)

2−13−2 拆 6 = 2×3、2 = (−1)×(−2)。交叉 2×(−2) + (−1)×3 = −4 − 3 = −7。第一行 2, −1 表示 2x−1，第二行 3, −2 表示 3x−2。

★ 试错示意：若改用 2 = (−2)×(−1)，十字变成

2−23−1 交叉 2×(−1) + (−2)×3 = −2 − 6 = −8 ≠ −7。这组丢掉，再换下一组。交叉和不对，不要硬凑。

例 11　12x² − 11x − 15 = (4x+3)(3x−5)

433−5 拆 12 = 4×3、−15 = 3×(−5)。交叉 4×(−5) + 3×3 = −20 + 9 = −11。

例 12　−6x² + 12 − x = −(2x+3)(3x−4)

原式没按降幂排，直接拆极易出错。先排成 −6x² − x + 12，再提 −1：−(6x² + x − 12)。括号里拆 6 = 2×3、−12 = 3×(−4)：

233−4 交叉 2×(−4) + 3×3 = −8 + 9 = 1。这个 1 是括号里 6x² + x − 12 的一次项系数，不是原式 −6x² − x + 12 的一次项系数。

5.4 二次齐次式

形如 ax² + bxy + cy²。单项 xy 的次数是 1+1 = 2，每项都是二次。把 y 暂时看成常数，做法与 ax² + bx + c 完全一样；写出因式时，把每个常数换成「这个常数 × y」。例如 (2x−1) 对应到齐次式是 (2x−y)，不是 (2x−1)y。

例 13　6x² − 7xy + 2y² = (2x−y)(3x−2y)（与例 10 只差常数后面的 y）

例 14　x² + 144y² − 25xy = (x−16y)(x−9y)

先排成 x² − 25xy + 144y²。16×9 = 144，(−16)+(−9) = −25。书上点出提速技巧：144 的因数对很多，从中间项 −25 入手往往更快——先看「和」再看「积」。常数项为正、一次项为负，两数同负。

5.5 系数和为零

定理：若 a + b + c = 0，则 ax² + bx + c = (x − 1)(ax − c)。

证明：由 a+b+c = 0 得 b = −(a+c)。

(x−1)(ax−c) = ax² − cx − ax + c = ax² − (a+c)x + c = ax² + bx + c。

★ c 本身带符号。例 15 里 c = −8，所以 ax − c = 3x − (−8) = 3x+8，不要写成 3x−8。

例 15　3x² + 5x − 8 = (x−1)(3x+8)（3+5−8 = 0）

例 16　12x² − 19xy + 7y² = (x−y)(12x−7y)（12−19+7 = 0）

补充结论：若 a − b + c = 0，则 ax² + bx + c = (x+1)(ax+c)。

这句话的来源是：a − b + c = 0 就是 a + (−b) + c = 0，定理先用在 ax² + (−b)x + c 上，得到 ax² − bx + c = (x−1)(ax − c)。再把这个等式里的 x 换成 −x，左边变成 ax² + bx + c，右边变成 (x+1)(ax+c)。不要只在 (x−1)(ax−c) 里把 x 写成 −x，却不把一次项系数改号。

二次齐次式 ax² + bxy + cy²：把定理里的 1 换成 y，同时把常数项 c 换成 cy。

  • a + b + c = 0 时，(x−y)(ax − cy)。
  • a − b + c = 0 时，(x+y)(ax + cy)。

只把 1 换成 y、第二因式仍写成 ax − c，例 16 会变成 (x−y)(12x−7)。展开是 12x² − 7x − 12xy + 7y，既不是齐次式，也不等于原式。

看到系数和为零，别再去拆因数对。这是竞赛题里常用的第一步：a+b+c = 0 说明 x = 1 是根，a−b+c = 0 说明 x = −1 是根。

四、易错点清单

#易错点正确做法
1 没先提公因式就上十字 结果不是最简。先一次提净，最后再检查每个因式还能不能提。
2 c < 0 时符号搞反 两因数异号，绝对值大的那个决定 b 的符号。只在首项系数已经提成正数、而且是 1 时直接用这张表。
3 没排降幂，或首项为负就硬拆 先排成降幂，看清谁是 a、b、c。首项系数仍为负，再提 −1（例 9、例 12）。不要在乱序时先提 −1，也不要先做系数和。
4 交叉和乘错列 交叉和是 p·s + q·r，不是同一行的 p·q，也不是 p·q + r·s。
5 忘记「分解到底」 x⁴ − 5x² + 6 = (x²−2)(x²−3) 之后还要检查。x²−2、x²−3 的判别式是 8 和 12，都不是完全平方数，在有理数范围内不能再分。不要改成「常数不是完全平方就不能分」：x²+5x+6 的常数 6 也不是完全平方，但它可以分。
6 二次齐次式漏写 y 例 13 写成 (2x−1)(3x−2) 是错的，应为 (2x−y)(3x−2y)。例 10 没有 y，(2x−1)(3x−2) 是对的，不要改。
7 试两组失败就断言「不能分解」 因数对可能没换全。是不是不能分，看步骤 ⑥ 的判别式，不看你试了几次。
8 不验算 把结果乘回去。积、和（或交叉和）都要看，30 秒就能自救。
